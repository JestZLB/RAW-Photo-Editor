# Provider 契约测试

契约测试覆盖 Provider 生命周期中的稳定行为，不依赖真实云端账户。

## 必须覆盖

- 成功：返回有效图像资产，写入新图层。
- 取消：任务进入 `cancelled`，不产生结果图层。
- 超时：映射为 `TIMEOUT`，给出可重试提示。
- 限流：映射为 `RATE_LIMITED`，不损坏项目。
- 认证失败：映射为 `AUTH_FAILED`，凭据不出现在错误中。
- 无效响应：JSON 或图像解析失败时拒绝落盘。
- 输入超限：尺寸/字节数超过能力声明时在提交前拒绝。
- 文档版本变化：结果仍作为新图层加入，由 UI 提示用户。

`crates/ai-provider` 与 `crates/app-core` 内的单元/集成测试是当前基线；真实端点联调需要单独的安全沙盒与授权。
