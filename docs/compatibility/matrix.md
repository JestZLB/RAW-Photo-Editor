## 图像格式

| 格式 | 导入 | 预览 | 导出 | 备注 |
| --- | --- | --- | --- | --- |
| JPEG | 是 | 是 | 是 | 质量 1–100 |
| PNG | 是 | 是 | 是 | 保留 alpha |
| TIFF | 是 | 是 | 是 | 依赖 `image` crate |
| WebP | 是 | 是 | 是 | VP8L 无损；仅 sRGB、8 位，不写入 EXIF/ICC |
| RAW（松下 RW2/RWL、尼康 NEF/NRW、索尼 ARW 等） | 是（基础） | 是 | 是 | rawler 0.7.2；解码后应用 RAW 的 EXIF Orientation（例如松下 RW2 的 90° 旋转）；无坐标编辑的旧 RAW 项目在打开时自动转正并重建预览，带蒙版/修复/AI 结果的旧项目保留原数据。已用松下 DC-FZ80、尼康 1 J1、索尼 DSC-RX100 样片验证导入/预览/导出，其他机型取决于相机数据库 |

位图最大输入：100MP，32MB。RAW 文件上限 200MB；解码后仍受 100MP 限制。RAW 分发需完成 LGPL 合规审查。

| 能力 | 状态 |
| --- | --- |
| CPU 参考渲染 | 已实现 |
| HSL 调色 | 已实现：色相 -180..180°、饱和度与明度 -100..100（CPU） |
| 曲线与色阶 | 已实现：5 点 RGB 主曲线、输入/输出黑白色阶与中间调（CPU） |
| LUT（.cube） | 已实现：1D（2..256）与 3D（2..64）cube 解析、显示 sRGB 三线性采样、0..1 强度混合；资产托管在项目目录，缺失或损坏返回 `LUT_INVALID`（CPU） |
| ICC 输入 | 已实现：读取 JPEG/PNG/TIFF/WebP 内嵌配置，识别 sRGB / Display P3 / Adobe RGB / 其他 RGB（矩阵 + TRC），导入时转换到线性 sRGB 工作空间；`curv`/`para`/`mntr` 曲线与表格曲线均支持 |
| ICC 输出 | 已实现：sRGB（不标注，通用约定）、Display P3（内置生成的配置）、原图配置（写回导入时的配置文件）；PNG 写 `iCCP`、JPEG 写 `APP2`、TIFF 写 `IccProfile` 34675。TIFF 的配置在导入侧用标签直读兜底，导出再导入仍识别为同一空间 |
| EXIF 导出 | 已实现：JPEG/PNG/TIFF 携带源 EXIF（TIFF 为编码后追写 IFD），方向标签归一、过期内嵌缩略图移除；`privacy` 策略额外删除 GPS；写不进去时按 `metadataWritten: false` 回报 |
| XMP 导出 | 未实现：可读取但无法写回，导出不携带 XMP |
| 16 位导出 | 已实现：PNG/TIFF 写出 RGBA16（走 CPU 线性管线，含自定义尺寸）；JPEG 返回 `BIT_DEPTH_UNSUPPORTED` |

| WGPU / WGSL 本地渲染 | 部分实现：基础照片、调色（不含清晰度/锐度/HSL/曲线色阶/LUT）、裁剪与 AI 结果图层；预览/导出自动回退 CPU |
| GPU 人像处理 | 未实现，当前回退 CPU |
| 本地 GPU AI 生成 | 未实现；云端生成由服务商 GPU 执行 |
| 多线程色彩算子 | 使用 rayon |
| GPU 设备丢失恢复 / 显存预算 / 分块 | 未实现 |

## 已知限制

- 历史栈不跨重启持久化；参数、图层与裁剪状态会持久化。
- 文字水印由前端 Canvas 光栅化后再交给后端合成；水印不参与画布预览，只在导出时出现。水印图片上限 8MB / 4096px。
- 本地 GPU 渲染仅覆盖子集（人像、清晰度/锐度、HSL、曲线/色阶、LUT、画笔/肤色/渐变/区域蒙版回退 CPU）；本地 GPU AI 生成未实现。
- ONNX 通道只支持输入 `[1,3,192,192]`、输出同尺寸的去噪模型；超分模型与需要其他输入尺寸的模型会被拒绝。CPU 推理耗时随模型和分辨率增长，超大照片会分很多块。
- Photo-HQ 通道需要支持 Vulkan 的 GPU 与驱动；没有 Vulkan 时不会退化为 CPU，AI 开关会被禁用并回退普通降噪。模型对皮肤纹理的平滑较强，80% 强度更自然；输入上限 1600px，超大照片的细节来自 4 倍重建后再缩小。运行期间显示已用时间与取消按钮（引擎不提供逐块百分比，因此不伪造进度）。首次启用 AI 的能力预检会多花几秒真实运行一次 32×32 推理。
- RAW 仅验证松下 DC-FZ80、尼康 1 J1、索尼 DSC-RX100 实拍样片，其余机型未逐一验证。
- 全分辨率导出在 CPU 上可能较慢；已有零散实测（预览命中缓存 0.3–0.9 ms、48³ LUT 解析 60 ms、WGPU 初始化 621 ms、6 MB 文档单次提交落盘 44 ms），但尚未建立系统性性能基线。
- 所有命令共用一把会话锁，但落盘已移到锁外（独立 `save_lock` + 快照序号防止旧快照覆盖新快照）：一个项目保存 6 MB 文档时，另一个项目的编辑实测最坏 1.0 ms（原先会被阻塞 44 ms 级）。逐层缩略图探测仍在锁内，单次约 10 µs。
- ICC 输入/输出已实现（含 TIFF），但未实现 HDR、软打样与 CMYK 转换；TIFF 的 EXIF 是自研 IFD 追写，需真实相机文件持续回归。
- 五官区域来自本地像素测量而非分割模型，侧脸、遮挡与浓妆会漏检；语义自动蒙版、背景/发丝精修、更新器与崩溃上报未实现。照片集支持整体重命名与先创建空集合。身体塑形（收窄 / 腿部拉长）只在人像图层蒙版内工作，不做自动体型识别；网格保护为 16×16 单元，不能逐像素冻结。
